# 🛍️ Online Shopping Sales Analysis Dashboard

- Tool Used: Microsoft Excel
- Data Size: 31,000+ records
- Goal: To visualize and interpret online sales trends using an interactive dashboard.

## 📊 Dashboard Features

- KPIs: Total Sales, Total Orders, Average Order Value, Quantity Sold
- Visuals:
- Gender-wise & Age-wise Sales
- Channel & Category Performance
- Top 5 States by Sales
- Monthly and Size-based Trends
- Filters: Interactive slicers for dynamic insights
- Design: Gradient theme (#1B1759, #CC0099, #2D90B3) for a modern visual look
